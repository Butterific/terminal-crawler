# Terminal Crawler
Terminal Crawler is a **dungeon style game** featuring `10` unique stages and `2` bossfights!

## Setup
 - Install dependices 
 `pip install -r requirements.txt`

## Running It Locally
 - Run `py main.py`


## About the project

This project took around **5** hours of time to make. I know semi-advanced python at the time of making this project. I just really wanted to make a cli game.
